# Storage icon sources

- Brand SVG paths imported in `src/provider-icons.jsx`: [Simple Icons](https://simpleicons.org/), CC0-1.0, distributed through the `simple-icons` development dependency.
- Microsoft OneDrive, Microsoft Azure, Amazon S3, and Oracle: Simple Icons v11.15.0, CC0-1.0. Local SVG files retain only the original path data, viewBox, and a brand color.
- Source package: https://www.npmjs.com/package/simple-icons/v/11.15.0
- Protocol and virtual-backend icons: [Lucide](https://lucide.dev/), ISC, through the existing `lucide-react` dependency.
- The OpenList 115 and 123 entries use custom numeric SVG marks; GuangYaPan uses Lucide's sun icon. These are identification icons, not official brand logos.

All icons are bundled with the application. No external image requests are required at runtime.
